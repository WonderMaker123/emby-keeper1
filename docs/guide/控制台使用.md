# 控制台使用指南

面向普通用户。**不需要懂配置文件**，所有设置都在网页上完成。

---

## 1. 打开控制台

浏览器访问：

```
http://服务器IP:1818/ui
```

输入部署时设置的 `EK_WEBPASS` 密码即可。登录有效期较长，无需频繁输入。

## 2. 首次使用：跟着「总览」页走

登录后进入**总览**页。如果配置不完整，页面顶部会出现橙色提示条，例如：

> 还有 3 项没配置好
> · 还没有 Telegram 账号，站点签到无法运行　去设置 →
> · 验证码识别未填 API Key，遇到验证码的站点可能签到失败　去设置 →
> · 通知未开启，签到结果不会推送到手机　去设置 →

按提示逐项点击即可。全部完成后，提示条会消失。

### 最少要配三样

| 顺序 | 项目 | 说明 |
|---|---|---|
| 1 | Telegram 账号 | 签到必需 |
| 2 | 签到站点 | 决定签哪些站 |
| 3 | Emby / Subsonic 账号 | 保号必需（如果只需要签到可跳过） |

## 3. 添加账号

进入左侧「账号」页。顶部有三个标签，一次只处理一类：

```
[ Emby ]  [ Subsonic ]  [ Telegram ]
```

### 3.1 添加 Emby 账号

1. 点右上角「添加 Emby 账号」
2. 在弹出的表单里填写：
   - **服务器地址**（必填）：`https://你的站点域名:443`
   - **用户名**（必填）
   - **密码**（必填）
   - 备注名称：可选，用于区分多个账号
   - **每次播放时长**：默认 5~10 分钟，按需调整
3. 点「添加账号」
4. **点右上角「保存配置」** —— 这一步不能忘，否则不生效

> 有 7 个进阶参数（客户端名、User-Agent、单独保活周期等）收在表单底部的
> 「高级选项」里，不确定就保持默认。

### 3.2 添加 Telegram 账号

1. 切到 `Telegram` 标签
2. 点「添加 Telegram 账号」
3. 填写**手机号**（必填），格式为带国家码：`+8613800138000`
4. 保持「启用签到」开启
5. 添加后保存配置

> **重要**：首次登录 Telegram 需要人工输入手机收到的验证码。容器内无法交互输入，
> 因此推荐先在本地（手机/电脑）用同一账号登录一次 Telegram，程序会复用会话。
> 若日志出现「非可交互终端」，说明会话缺失，需按上句处理。

### 3.3 停用而不删除

账号列表左侧有开关。关闭后该账号不参与签到/保活，配置保留，随时可再打开。

## 4. 选择签到站点

进入「签到站点」页。三种模式：

| 模式 | 适用 | 行为 |
|---|---|---|
| **默认推荐** | 大多数人 | 使用项目维护的推荐站点清单，最省心 |
| **全部站点** | 想要全部积分 | 签到所有已知站点（100+，耗时长） |
| **手动选择** | 只关注特定站点 | 自己在下方卡片里点选 |

### 4.1 手动选择

切到「手动选择」后，下方出现站点卡片网格：

- 点击卡片即可选中/取消（选中时左上角显示对勾）
- 顶部可**搜索**站点名，或按**分类**筛选
- 「选推荐」一键勾选推荐站点；「清空」全部取消

> 卡片右侧标有「验证码」的站点，签到时会触发图片验证码，需要配置好识别（见第 6 节）。

### 4.2 添加内置清单里没有的站点

如果站点不在列表里，但它的 Telegram 机器人支持「发送面板消息 + 点击签到按钮」：

1. 点右上角「添加自定义站点」
2. 填写**机器人用户名**（在 Telegram 打开该机器人，看它的 `@username`，不含 `@`）
3. 可填显示名称，方便辨认
4. 其余参数保持默认，点「确定」
5. 保存配置

添加后会出现在「自定义站点」列表里，也会自动加入签到范围。

## 5. 配置通知（可选但推荐）

进入「结果通知」页。推荐用 Telegram 机器人直推。

### 5.1 分步操作

1. 在 Telegram 搜索 **`@BotFather`**，发送 `/newbot`，按提示创建机器人
2. BotFather 会回复一串 **Token**，形如 `123456789:ABCdefGhIJK...`，复制它
3. 在 Telegram 里找到刚创建的机器人，**点「开始」并发一条任意消息**
   （不发消息的话，机器人无法给你推送）
4. 搜索 **`@userinfobot`** 并给它发消息，它会回复你的数字 ID，这就是 **Chat ID**
5. 回到控制台：
   - 打开「通知开关」
   - 推送方式选「Telegram 机器人」
   - 填入 Bot Token 和 Chat ID
6. **保存配置**
7. 点「发送测试通知」，几秒内手机应收到消息

### 5.2 收不到怎么办

页面会显示 Telegram 返回的具体原因，常见三种：

| 提示 | 原因 | 解决 |
|---|---|---|
| `chat not found` | Chat ID 不对，或没先给机器人发过消息 | 先给机器人发条消息；群组 ID 是负数 |
| `Unauthorized` | Token 错误 | 回 @BotFather 重新获取 |
| `bot was blocked` | 你把机器人屏蔽了 | 在 Telegram 里解除屏蔽 |

## 6. 验证码识别

进入「系统设置」页，找到「验证码识别」区块。

| 方式 | 准确率 | 说明 |
|---|---|---|
| **AI 识别**（推荐） | 高 | 需要填 API Key，失败时自动退回本地 |
| 本地识别 | 较低 | 免费、离线，但字体稍有变化就容易认错 |

选择 AI 后填入 **API Key**，模型名称与接口地址留空即使用内置默认值。
保存后立即生效。

> 若签到日志里频繁出现「验证码识别失败」，多半是 Key 未填或额度用尽。

## 7. 执行时间

同一页面的「站点签到」与「媒体服保活」区块，用时间选择器设置：

```
签到时间段   [11:00] 至 [23:00]
预设： [上午] [下午] [晚间] [白天全天]
每天在 11:00 ~ 23:00 之间随机签到一次
```

程序会在该区间内**随机**挑一个时刻执行，避免所有用户同一秒请求站点。

间隔可选「每天 / 每隔 N 天 / 每隔 X~Y 天随机」。

## 8. 查看日志与手动触发

### 8.1 立即运行

总览页右上角「**立即运行一次**」，不必等到计划时间。
点后日志页会显示实时进展。

### 8.2 运行日志

左侧「运行日志」页：

- 自动刷新（3 秒），可关闭
- 按级别筛选：全部 / 仅错误 / 警告及以上 / 成功
- 关键词搜索
- 「跟随最新」勾选后自动滚到底部；向上翻看时不会被打断

顶部徽标显示业务进程状态：**业务运行中** / **业务未运行**。
若显示未运行，说明业务进程异常，需查看容器状态。

## 9. 保存与生效

- 修改后顶部和底部都会出现「保存配置」按钮，**必须点击才生效**
- 有未保存改动时，底部会有黄色提示条
- 点「放弃更改」可还原到上次保存的状态
- 保存后业务进程**自动热重载**，无需重启容器

## 10. 常见问题

**Q：改完配置没反应？**
A：检查是否点了「保存配置」。保存成功后右上角会弹出提示。

**Q：日志显示「今日已经签到过了」？**
A：正常。说明该站点今天已经签过，程序不会重复签到。

**Q：签到显示「Failed to invoke ... GetBotCallbackAnswer」？**
A：点击签到按钮时 Telegram 响应超时，程序会自动重试。若随后出现「今日已经签到过了」，
说明实际已成功，属正常现象。

**Q：容器重启后要重新登录 Telegram？**
A：说明 `/app/data` 没有挂载到宿主机。该目录存有会话文件，务必挂载。

**Q：怎么改控制台密码？**
A：修改容器的 `EK_WEBPASS` 环境变量后重建容器。

**Q：忘记密码怎么办？**
A：`docker inspect embykeeper | grep EK_WEBPASS` 查看，或重建容器时重设。
